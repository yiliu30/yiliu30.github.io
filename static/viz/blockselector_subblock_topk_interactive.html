The source branch is a draft of PR #8335 (not yet merged at creation). It supports CUDA, FP16/BF16 Q/K, a protected KV prefix, and native MHA/MQA/GQA mapping.

Important interpretation

The score is an approximation of Q-block relevance to a KV block. It is not the exact probability mass from full 64×64 token attention. Top-k uses the score rank rather than a Softmax probability.

The output has only KV-block IDs and counts. V is not used by this selector; the selected-key attention provider consumes Q/K/V afterward.

The data here are synthetic but every pooled mean, dot product, LogSumExp, budget and output array is recomputed on interaction. No CDN, tracking, external scripts or build dependencies.
