Skip does not drop the tile. Each two-key cluster is represented by one mean key and mean value with a virtual logit correction of ln(2). This has the same softmax result as replacing both individual keys and values by that cluster mean.

08  Reading the equations

Paper §5.2 ↗
J = 1 − exp(−||q||² · ⟨tr ΣK⟩ / (2d²))

K variance measures the missing exponential weight from mean-key replacement (softmax-normalizer effect). If K is identical within clusters, J = 0.

R = ||q|| / d · ⟨||ΣKV||F / ||V̄||⟩

K–V covariance measures the shift in the value favored by attention. V variation alone is not sufficient: K and V must be correlated within the cluster for this first-order term.

m̃ = ½ (m̃ from Q̄·K + m̃ from Q·K̄)

Mass is estimated from two corrected low-cost views. This demo computes both from the numeric Q/K/V and also displays the exact mass for comparison.

Ẽ = m̃ · (J + R) · √wₕ

Output head energy supplies a relative head-level multiplier. The score is a heuristic, not an exact per-tile L₂ error or an error bound.

Route: Refine if (0.22 × Nₜ × Ẽ / 2) ≥ π; else Skim if (0.78 × Nₜ × Ẽ) ≥ π; otherwise Skip.
